# Attached asset authority

For storyboard temporal roles, follow [action physics and timing](../skills/director-pack-skills/references/action-physics-and-timing.md). Pose intent identifies an entry, intermediate or exit instant, not an instruction to freeze physical motion.

User instruction, 2026-10-03: generation prompts must use bound canonical asset attachments as the authority for character and prop identity, design, colors, materials, geometry and mechanisms, and for location architecture, surfaces, landmarks, statues and background.

Storyboards supply scene composition, staging, framing and pose intent only. They never replace the attached asset or location designs. Resolve storyboard discrepancies from the canonical attachments. Use the actual runtime Picture labels in the prompt. The authored shot plan controls action, timing, population and physical state.

Keep storyboard reference enabled when requested, while preserving one full-screen shot per panel and excluding storyboard layout from the generated video.
